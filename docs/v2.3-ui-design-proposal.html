Options Page Proposal

CodeToSpan Settings

設定項目を用途ごとに整理し、除外ドメインの行操作を左端に寄せる案です。

Page Language

ページの言語とブラウザ言語を比較して、翻訳対象になりやすいページだけ処理します。

Code Element Rules

個々の code 要素を変換対象にするかどうかを決めます。

サイズを持つ code 要素は変換しません。

Translate Attributes

機械翻訳から除外したい要素に属性を追加します。

Reset Settings

除外ドメイン以外の設定を初期値に戻します。

Exclude Domains

example.com
very-long-subdomain-for-translation-documents.example.co.jp

v2.3 では hostname の完全一致で除外します。サブドメイン一致やURLパターンは対象外です。

Open tabs need reload

設定変更後、すでに開いている対象タブは再読み込みが必要です。対象タブでは拡張機能アイコンに `R` バッジが付きます。

Store page update

v2.3 のUI変更、リロード通知、ドメイン除外操作が伝わるように Chrome Web Store の説明・スクリーンショット・更新内容も見直します。
