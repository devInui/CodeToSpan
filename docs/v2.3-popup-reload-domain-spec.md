# CodeToSpan v2.3 Popup / Reload / Domain 仕様書

## 目的

この仕様書は、v2.3 の追加修正として確定した popup のリロード挙動、古い設定の検出、ドメイン除外操作、popup / option ページのUIブラッシュアップ、ユーザー向けQ&A作成タスクをまとめるものです。

## 確定仕様

### STOP/RUN 切替時のリロード確認

- STOP/RUN 切替時のリロード挙動を設定できるようにします。
- デフォルトは「リロード前に確認する」です。
- 自動リロード設定が有効な場合、STOP/RUN 切替時に確認せず現在タブをリロードします。
- 自動リロード設定が無効な場合、ブラウザ標準の `confirm()` で確認します。
- 確認文言は次の通りです。
  - `Reload current tab?`
- リロードした場合、リロード完了後に popup の `Outdated Settings Detected.` 状態が最新状態へ更新される必要があります。

### Outdated Settings Detected

- popup の警告文言は次のまま維持します。
  - `! Outdated Settings Detected.`
- popup の横幅は、この文言が1行で収まる幅にします。
- 現在ページが `Language-Based` または `Exclude Domains` によって除外中の場合、通常は `Outdated Settings Detected.` を表示しません。
- ただし、option ページの変更によって現在ページの除外状態が変わった場合は、リロードが必要なため警告を表示します。
  - 除外対象になった
  - 除外対象から外れた

### 拡張機能アイコンのバッジ

- 現在タブにリロードが必要な場合、拡張機能アイコンにバッジを表示します。
- バッジ文字は `R` です。
- バッジ背景色はオレンジです。
- 現在タブがリロード不要になったらバッジを消します。
- バッジ表示の判定は、popup の `Outdated Settings Detected.` と同じリロード要否ロジックに揃えます。

### popup の Show More 領域

- `Options` と `Check Domain` は初期表示では隠します。
- アイコン付きテキストボタン `Show More` を追加します。
- 展開後は `Show Less` に切り替えます。
- 開閉状態は `chrome.storage.local` に保存します。
- 次回 popup を開いたときも前回の開閉状態を復元します。
- 展開時の並び順は次の通りです。
  1. `Options`
  2. `Check Domain`
- `Options` は従来のテキストリンクではなく、ボタン風UIにします。
- `Options` と `Check Domain` の見た目は揃えます。

### popup のドメイン確認

- `Check Domain` を押すと、現在ページの `hostname` を表示します。
- 表示する値は、既存の除外判定と同じ `window.location.hostname` に合わせます。
- `https://`、パス、クエリは含めません。
- コピー機能は追加しません。
- `Check Domain` 後は、hostname と短い `Add` ボタンを表示します。
- hostname がすでに `excludedDomains` に登録済みの場合:
  - ボタンを無効化します。
  - ボタン文言は `Added` にします。
  - アラートは出しません。
- `chrome://` や `about:` など hostname を取得できないページでは:
  - `Domain unavailable` と表示します。
  - `Add` ボタンは表示しません。
- 長い hostname でも popup 全体の横幅を広げません。
- hostname 表示欄だけ横スクロール可能にします。
- `Add` / `Added` ボタンは常に見える位置に固定します。

### popup から Exclude Domains へ追加

- `Add` を押すと、現在ページの hostname を `excludedDomains` に追加します。
- v2.3 では既存のマッチング方式を変更しません。
- 除外判定は引き続き hostname の完全一致です。
- サブドメイン一致やURLパターン対応は v2.3 では実装しません。
- ドメイン追加後、ブラウザ標準の `confirm()` でリロード確認をします。
- 確認文言は次の通りです。
  - `Domain added. Reload current tab?`
- ユーザーがOKした場合のみ現在タブをリロードします。
- キャンセルした場合はリロードせず、リロードが必要な状態として扱います。

### option ページの Exclude Domains UI

- Exclude Domains の削除ボタンは、各ドメイン行の右端ではなく左端に配置します。
- option ページ側のドメイン登録・削除の意味は現状維持です。
- v2.3 ではドメイン照合ルールの拡張は行いません。

## 新しいデザイン案

### popup

- popup はコンパクトな固定幅にします。
- 幅の基準は `! Outdated Settings Detected.` が1行で収まることです。
- 初期表示は重要な操作だけに絞ります。
  - アプリ名
  - RUN/STOP スイッチ
  - 現在状態
  - 必要な場合のみ警告
  - `Show More`
- `Options` と `Check Domain` は `Show More` 展開時のみ表示します。
- 操作ボタンの見た目を揃えます。
  - `Reload`
  - `Show More` / `Show Less`
  - `Options`
  - `Check Domain`
  - `Add` / `Added`
- 装飾は控えめにし、ツールとして使いやすい見た目にします。
- ドメイン表示行は次の構成にします。
  - 左: 横スクロール可能な hostname 表示欄
  - 右: 固定幅の `Add` / `Added` ボタン

### option ページ

- 現在の1ページ構成は維持します。
- セクションのまとまりを見やすくします。
  - Code conversion exclusions
  - Language behavior
  - Translate attributes
  - Exclude Domains
  - Reset
- 各設定項目の余白とラベルの見た目を揃えます。
- Exclude Domains の行は、左に削除ボタン、右にドメイン名を配置します。
- 行の高さを安定させ、リストとして読みやすくします。
- 説明文は補足情報として控えめな見た目にします。
- 英語・日本語の両ロケールで文字がはみ出さないことを確認します。

## ユーザー向けQ&A作成タスク

ユーザー向けのQ&Aドキュメントを作成します。最低限、次の内容を含めます。

- RUN/STOP は何を切り替えるのか
- なぜ現在タブのリロード確認が出るのか
- `Outdated Settings Detected.` は何を意味するのか
- 拡張機能アイコンの `R` バッジは何を意味するのか
- `Language-Based` がONのとき、なぜ処理されないページがあるのか
- `Exclude Domains` はどのように一致判定されるのか
- なぜ `example.com` では `sub.example.com` が除外されないのか
- v2.3 でURLパス単位の除外に対応しない理由
- popup の `Add` は何を追加するのか
- `Domain unavailable` が表示されるのはどのような場合か

## v2.3 では扱わないこと

- サブドメインワイルドカード一致。
- URLパス単位の除外。
- popup のドメインコピー機能。
- ブラウザ標準 `confirm()` を独自確認UIへ置き換えること。
