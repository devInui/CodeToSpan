# Chrome 拡張機能の手動確認

自動テストが通った後、または実際の Chrome 拡張機能ランタイムが必要な挙動を確認するときに、このチェックリストを使用します。

## パッケージ化されていない拡張機能を読み込む

1. Chrome を開き、`chrome://extensions` に移動します。
2. `デベロッパー モード` を有効にします。
3. `パッケージ化されていない拡張機能を読み込む` をクリックします。
4. `manifest.json` があるリポジトリのルートディレクトリを選択します。
5. `CodeToSpan for Translation` が拡張機能エラーなしで表示されることを確認します。

## オプションページとポップアップを開く

1. 拡張機能の `詳細` をクリックし、`拡張機能のオプション` を開きます。
2. オプションページが読み込まれ、設定項目が表示されることを確認します。
3. 拡張機能アクションを固定するか開き、ポップアップを開きます。
4. ポップアップが開き、Run/Stop トグルと Options リンクが表示されることを確認します。
5. ポップアップ内の Options リンクを使い、同じオプションページが開くことを確認します。

## 小さなテストページを用意する

次の内容をリポジトリ外のローカル HTML ファイルとして保存するか、インラインの `<code>` 要素を含む既存のプログラミングドキュメントページを使用します。

```html
<!doctype html>
<html lang="en">
  <body>
    <p>Inline code: <code>const value = 1;</code></p>
    <pre><code>function demo() { return true; }</code></pre>
  </body>
</html>
```

Chrome でそのファイルを開きます。ローカルファイル上で拡張機能の content script が動作しない場合は、`chrome://extensions` から対象拡張機能の `ファイルの URL へのアクセスを許可する` を有効にするか、公開されているプログラミングドキュメントページを使用します。

## Code-to-Span の動作を確認する

1. ポップアップで拡張機能が `RUN` になっていることを確認します。
2. ページの `lang` がブラウザの言語と異なるページを使うか、オプションで一時的に言語検出を無効にします。デフォルトの言語検出設定では、ページ言語がブラウザ言語と一致する場合は処理がスキップされます。
3. テストページを再読み込みします。
4. Chrome DevTools でインラインの `<code>` 要素を調べます。
5. 対象となるインラインコードが `<span>` 要素に置き換わっていることを確認します。
6. デフォルトの `<pre>` など、除外対象の親タグ内にあるコードが変換されないことを確認します。
7. 該当オプションが有効な場合、`<pre>` ブロックに `translate="no"` が付与されることを確認します。

## 古い設定の警告を確認する

1. テストページを開いたままにします。
2. オプションページを開き、ページ処理に影響する設定を変更します。
3. まだ読み込んだままのテストページ上でポップアップを開きます。
4. ポップアップに古い設定の警告と Reload ボタンが表示されることを確認します。
5. Reload をクリックし、アクティブなタブが再読み込みされることを確認します。
6. もう一度ポップアップを開き、ページが最新設定を使用している場合に警告が消えることを確認します。

## Run/Stop トグルの再読み込みを確認する

1. テストページ上でポップアップを開きます。
2. `RUN` から `STOP` に切り替えます。
3. アクティブなタブが再読み込みされることを確認します。
4. 再読み込み後のページを調べ、停止中はコード要素が変換されないことを確認します。
5. `STOP` から `RUN` に戻します。
6. アクティブなタブが再読み込みされ、対象となるコード要素が再び変換されることを確認します。

## 言語設定とデフォルト設定を確認する

1. オプションページから設定をリセットします。
2. デフォルト設定が次の内容であることを確認します。
   - enabled: `true`
   - 除外する親タグ: `<pre>` のみ
   - 言語検出: 有効
   - スタイル付き code タグのスキップ: 無効
   - `<pre>` への `translate="no"` 付与: 有効
   - 除外ドメイン: 新規インストールまたは新規 Chrome プロファイルでは空
3. 既存の除外ドメインは、オプションページのリセット操作では初期化されません。この確認の前に手動で削除するか、新規インストールまたは新規 Chrome プロファイルで空の初期値を確認します。
4. 言語検出が有効な状態で、ページの `lang` がブラウザ言語と異なるページを使い、処理が実行されることを確認します。
5. ページの `lang` がブラウザ言語と一致するページを使い、処理がスキップされることを確認します。
6. オプションで言語検出を無効にし、テストページを再読み込みして、ページ言語に関係なく処理が実行されることを確認します。

## 記録する内容

Chrome のバージョン、OS、テストページの URL、使用した設定、合否結果、ページまたは拡張機能ポップアップで発生したコンソールエラーを記録します。
