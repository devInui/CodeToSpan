> Improves machine translation of programming docs by protecting inline code and reducing translation layout issues.

### Long description

候補:

```text
CodeToSpan for Translation helps programming learners read translated documentation more comfortably.

Machine translation can sometimes break programming documentation because inline code, keywords, and short code fragments are treated differently from normal text. CodeToSpan reduces these issues by replacing eligible code tags with span tags before translation.

Main features:
- Convert eligible code tags to span tags on documentation pages.
- Turn processing ON or OFF from the popup.
- Configure which parent elements are processed from the Options page.
- Skip pages whose language appears to match the browser language.
- Exclude specific hostnames from processing.
- Check the current tab hostname from the popup and add it to Exclude Domains.
- Show an R badge on the extension icon when an already open tab needs reload after settings change.
- Show "Outdated Settings Detected." in the popup when the current tab is using old settings.

v2.3 improves the popup and Options page workflow. Options and Check Domain are now available under Show More, the Options page is organized by setting purpose, and reload-required states are easier to understand.

Important notes:
- After changing settings, already open target tabs need to be reloaded before the latest settings are applied.
- When RUN / STOP is changed, CodeToSpan asks whether to reload the current tab. Automatic reload can be enabled in Options.
- Some web apps that generate or hydrate code elements dynamically may behave unexpectedly. If buttons or links become unresponsive, stop the extension for that page or add the hostname to Exclude Domains, then reload the page.
```

```md
# CodeToSpan for Translation

CodeToSpan is a Chrome extension for people who read programming documentation through machine translation.

Machine translation can distort inline code, keywords, and short code fragments. CodeToSpan reduces these issues by converting eligible `<code>` elements into `<span>` elements before translation.

## Features

- Converts eligible code tags to span tags.
- RUN / STOP toggle from the popup.
- Reload-required warning for already open tabs.
- `R` badge on the extension icon when a tab needs reload.
- `Check Domain` in the popup to inspect the current hostname.
- Quick add flow from the popup to Exclude Domains.
- Options page for page language checks, code element rules, translate attributes, settings management, and excluded domains.
- Hostname-based Exclude Domains.

## Usage

1. Install the extension and open a programming documentation page.
2. Turn CodeToSpan `RUN` from the popup.
3. Use browser translation on the page.
4. If settings are changed, reload already open target tabs when the `R` badge or `Outdated Settings Detected.` appears.
5. Use `Show More` > `Check Domain` to confirm the current hostname and add it to Exclude Domains when needed.

## Important Notes

- Already open tabs need reload after settings changes.
- RUN / STOP changes ask whether to reload the current tab. Automatic reload can be enabled in Options.
- Exclude Domains uses exact hostname matching. `example.com` does not match `sub.example.com`.
- Some dynamic web apps may behave unexpectedly if code elements are rewritten. If buttons or links become unresponsive, stop the extension for that page or add the hostname to Exclude Domains, then reload.

## Additional Information

- Chrome Web Store: https://chromewebstore.google.com/detail/codetospan-for-translatio/ebnohmjaodacnofjhknnjjnchanjleng
- Release notes: ./RELEASE.md
```
